## 프로모션 텍스트 (170자 이내, 언제든 수정 가능)
넷플릭스, 어도비, 노션… 흩어진 구독을 한눈에 모아 유지·재검토·해지 후보로 정리해요. 로그인 없이, 이 기기에만 안전하게.

## 설명 (Description)
여러 개의 SaaS 구독을 쓰다 보면 어느새 매달 얼마가 나가는지도 모르게 됩니다. Renewly는 등록한 구독을 한눈에 모아 보여주고, 4가지 기준으로 평가해 유지할지 다시 볼지 해지할지 판단하는 걸 도와주는 앱입니다.

주요 기능
- 구독 등록: 서비스명, 금액, 결제일을 등록하면 이번 달 총 비용을 바로 확인
- 4축 가치 평가: 사용 빈도, 업무 중요도, 대체 가능성, 비용 부담을 답하면 유지·재검토·해지 후보를 제안
- 결정함: 상태별로 구독을 모아보고, 해지 후보 반영 시 예상 절감액을 확인
- 결제 캘린더: 이번 달 결제 예정 구독을 날짜순으로 확인, 결제일 히트맵 제공
- 인앱 알림: 결제일이 다가오거나 오래 재검토하지 않은 구독을 다시 확인하도록 알려드림

데이터는 이 기기에만
Renewly는 로그인이나 회원가입이 없습니다. 입력한 모든 정보는 이 기기에만 저장되며 서버로 전송되지 않습니다. 앱을 삭제하면 데이터도 함께 사라집니다.
